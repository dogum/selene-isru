# Video showcase

SELENE-ISRU includes four checked-in, reproducible demonstrations. Each video
is rendered from the production application with scripted browser state and no
browser chrome. The MP4 files are silent by design so narration, music, or
platform-native audio can be added without removing an embedded track.

| Video | Length | Purpose |
|---|---:|---|
| [Cinematic product tour](media/selene-isru-cinematic-demo.mp4) | 31.6 s | Branded Equatorial fly-through with live 1,000 → 10,000 kg/day trade-study response and KPI ribbon. |
| [Custom Site workflow evidence](media/custom-site-sandbox-demo.mp4) | 24.8 s | Direct Planner/import/Explore/save/export workflow used by the release smoke test. |
| [Detailed Custom Site cinematic](media/custom-site-cinematic-60s.mp4) | 60.0 s | Seven-beat story from blank terrain through staged assets, topology validation, route inspection, and Explore. |
| [Fast Custom Site cinematic](media/custom-site-cinematic-30s.mp4) | 30.0 s | Two-times-speed companion cut derived from the detailed master for shorter shares. |

## Storyboards

### Cinematic product tour

[![Equatorial lunar industry overview](screenshots/equatorial-assets/base-overview-after-desktop.png)](media/selene-isru-cinematic-demo.mp4)

The product tour uses deterministic camera tracks, composited captions, a live
KPI ribbon, and an animated production target. It finishes with the public
project URL.

### Detailed and fast Custom Site cinematics

[![Connected Custom Site in Planner](screenshots/custom-site/reference-planner-desktop.png)](media/custom-site-cinematic-60s.mp4)

The detailed master follows:

1. blank deterministic Equatorial terrain and a closed topology gate;
2. excavation, hauling, and processing placement;
3. power, product, and construction routes;
4. the completed eight-asset/eight-connection gate-open design;
5. power-route engineering assumptions and spatial consequences;
6. the Planner-to-Explore transition; and
7. a cinematic site fly-around and project call to action.

The [30-second fast cut](media/custom-site-cinematic-30s.mp4) retains the same
frames and captions at two-times speed. The one-minute version is the editing
master when a different pace or platform-specific crop is needed.

### Workflow evidence

[![The saved Custom Site in Explore](screenshots/custom-site/reference-explore-desktop.png)](media/custom-site-sandbox-demo.mp4)

The workflow video is intentionally less cinematic. It is generated by the
same automation that verifies placement, versioned import, topology evaluation,
Planner/Explore consistency, study-library save, JSON export, and mobile
review.

## Reproduce the videos

Install Node.js 22, pnpm 10.33, Chrome, `ffmpeg`, and `ffprobe`. Then build and
serve the production app:

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm --filter @selene-isru/app preview --host 127.0.0.1 --port 4173
```

In a second terminal:

```bash
pnpm demo:cinematic -- \
  http://127.0.0.1:4173/selene-isru/ \
  docs/media/selene-isru-cinematic-demo.mp4

pnpm demo:custom-cinematic -- \
  http://127.0.0.1:4173/selene-isru/ \
  docs/media/custom-site-cinematic-60s.mp4 \
  docs/media/custom-site-cinematic-30s.mp4

pnpm evidence:custom -- http://127.0.0.1:4173/selene-isru/
```

Set `CHROME_PATH` when Chrome is not installed in a standard location. Set
`FFMPEG_PATH` or `FFPROBE_PATH` when those tools are not on `PATH`. Set
`KEEP_RAW=1` to preserve intermediate WebM captures for debugging or
alternative post-production.

The cinematic generators use the opt-in `?demo=1` bridge. It is inactive
during normal application use and exposes only deterministic camera, parameter,
and staged Custom Site capture controls.
